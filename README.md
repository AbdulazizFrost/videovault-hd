# VideoVault HD — Профессиональная Локальная Видеотека для Windows 11

**VideoVault HD** — это современная, высокопроизводительная веб-система для каталогизации, потокового просмотра и прямого скачивания видеофайлов из локальной папки Windows.

По умолчанию настроена на чтение файлов из папки:
```
D:\QIZLAR BAZMI HD
```

---

## ⚡ Ключевые возможности

1. **Реальное взаимодействие с файловой системой:**
   - Автоматическое сканирование папки при старте сервера.
   - Поддержка форматов: `.mp4`, `.mkv`, `.avi`, `.mov`, `.webm`, `.m4v`.
   - Фоновое отслеживание изменений (`fs.watch`): новые и удалённые видео автоматически обновляются в интерфейсе.
   - Кнопка **«Обновить»** для мгновенной ручной синхронизации.

2. **Потоковое воспроизведение (HTTP Range 206):**
   - Перемотка и мгновенный запуск многогигабайтных видеофайлов (например, 7.35 GB) без полной загрузки в оперативную память.
   - Поддержка встроенного HTML5-видеоплеера с полноэкранным режимом, громкостью, горячими клавишами (`Пробел`, `F`, `Esc`).

3. **Скачивание оригиналов без перекодирования:**
   - Прямая потоковая передача (`fs.createReadStream`) исходного файла на устройство.
   - 100% сохранение оригинального качества, разрешения, битрейта и аудиодорожек.
   - Корректная поддержка RFC 5987 / RFC 6266 для кириллицы, узбекских символов (`oʻ`, `gʻ`), пробелов и спецсимволов.

4. **Генерация миниатюр и метаданных:**
   - Автоматическое извлечение длительности, разрешения (1080p, 4K), кодеков через установленный FFmpeg.
   - Автоматическое создание превью (сохраняются в `.cache/thumbnails`).
   - Если превью недоступно — аккуратная векторная заглушка (без фиктивных картинок).

5. **Безопасность корпоративного уровня:**
   - Полная защита от Directory Traversal (LFI): доступ разрешён строго внутри сконфигурированной папки.
   - Клиент оперирует безопасными ID (Base64url), не передавая прямые пути к файлам.
   - Сервер по умолчанию привязан к `127.0.0.1` (защита от несанкционированного доступа из внешней сети).

## 🛠 Технологический стек

- **Backend:** Node.js 24+, Express, TypeScript, TSX, FFmpeg CLI.
- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS, Lucide React Icons.
- **Оркестрация:** Concurrently (запуск фронтенда и бэкенда одной командой).

## 🚀 Инструкция по запуску на Windows 11

### Способ 1: В один клик (самый простой)

Просто дважды нажмите на файл:
```
start-windows.bat
```
Скрипт автоматически проверит окружение, установит недостающие пакеты при необходимости, запустит сервер и откроет сайт в вашем браузере.

---

### Способ 2: Запуск через терминал (одна команда)

1. Откройте терминал PowerShell в папке проекта (`c:\Users\Abdulaziz\Desktop\сайт чтобы скачать`).
2. Запустите:
```powershell
npm run dev
```
3. Откройте браузер по адресу:
```
http://127.0.0.1:5173
```

---

### Способ 3: Запуск в режиме Production (единый сервер)

Если вы хотите запустить проект в автономном режиме на одном порту `5000`:
```powershell
# 1. Сборка проекта
npm run build

# 2. Запуск сервера
npm start
```
После этого сайт доступен по адресу: `http://127.0.0.1:5000`.

## ⚙ Конфигурация (.env)

Файл `.env` в корне проекта позволяет настроить работу системы:

```env
# Порт и хост сервера
PORT=5000
HOST=127.0.0.1

# Путь к локальной папке видео на Windows
VIDEO_DIR="D:\QIZLAR BAZMI HD"

# Папка для кэширования миниатюр
THUMBNAIL_DIR="./.cache/thumbnails"
```

## 🔍 Диагностика и устранение неполадок

- **Папка `D:\QIZLAR BAZMI HD` не найдена:**
  - Убедитесь, что диск `D:` подключен.
  - Если видеофайлы лежат в другой папке, укажите актуальный путь в `.env` (параметр `VIDEO_DIR`) и нажмите кнопку «Обновить» в интерфейсе.
- **Файлы формата MKV или AVI:**
  - Браузеры Chrome, Edge и Firefox аппаратно декодируют H.264/AAC в контейнерах MP4/WebM.
  - Некоторые кодеки в MKV/AVI могут не поддерживаться встроенным HTML5-видеоплеером браузера. В таком случае VideoVault HD покажет аккуратное уведомление с предложением скачать оригинальный файл в один клик для воспроизведения в VLC.
- **FFmpeg:**
  - Программа автоматически находит системный `ffmpeg.exe` для извлечения битрейта, разрешения и создания превью.
